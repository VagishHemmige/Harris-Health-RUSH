Original Stata code (2015)

Author

Vagish Hemmige

The analysis as it was run for the article: one Stata .do file, dated 15 January 2015, written by Vagish Hemmige. It is kept unchanged as the record of what was done, apart from two changes listed in its header: the cd command’s folder on the analyst’s computer is removed, and the line endings are Unix. The R scripts are the version this site explains; every way they differ from this file is on Differences from the original code.

RcodeSource code

The file is available at:

  • stata/RUSH_analysis_2015-01-15.do

It is shown below as text, in the parts its own comments mark, each with a link to the R page that explains it; nothing on this page runs it. The same parts appear, folded, on each R page beside the code that replaces them.

//Original Stata analysis for the RUSH study (JAIDS 2015, doi:10.1097/QAI.0000000000000578).
//Kept as the record of what was done. Changes from the 2015 file: the local folder path in
//the cd command is removed, and line endings are Unix. Nothing else is changed.

//Data analysis for RUSH study
//January 2015
//Vagish Hemmige

clear
set more off
set scheme lean1
global DateOfAnalysis 1-15-2015
//The working directory was a folder on the analyst's computer holding the de-identified
//workbooks; its path is removed here. Set it to the folder that holds them before running.
//cd "<folder holding the de-identified workbooks>"

//Now we start logging the analysis
capture log close
log using "RUSH $DateOfAnalysis.log", replace

The analysis as it was run for the article: one Stata .do file, dated 15 January 2015, written by Vagish Hemmige. It is kept unchanged as the record of what was done, apart from two changes listed in its header: the `cd` command's folder on the analyst's computer is removed, and the line endings are Unix.
