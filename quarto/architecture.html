Architecture

The current implementation: scripts, data flow, and the objects passed between them. Written on 8 November 2026 against every script in R/ and tests/synthetic/. The scripts have been run on synthetic data only; they have not yet been run on the study data.

Running order

R/main.R sources the scripts in this order. Each script runs in the global environment and leaves the objects listed for later scripts. The only files written are the HTML tables in tables/.

Order Script Needs Produces Data
1 R/setup.R — Attached packages; every constant —
2 R/functions.R Packages Helper functions —
3 R/01_import_data.R 1, 2; RUSH_DATA_DIR study_wide, control_wide (one row per patient) Study data

Data flow

Key mechanisms

  • Within-patient models. Every conditional model goes through fit_conditional_logit(), which adds strata(patient_number) and uses the exact conditional likelihood. In 04, characteristics appear only in interactions with post_visit; in 05 the subgroup models are the full factorial post_visit * rush_era * characteristic, since a characteristic can differ between a patient’s eras. fit_conditional_logit() fits to complete rows from patients whose outcome varies, with categories then empty dropped, as Stata’s clogit drops uninformative groups; reference levels therefore follow the estimation sample, and effect_by_level() lists dropped categories as not estimable.
  • Stata’s category numbering. encode_like_stata() orders factor levels by byte order, so reference levels match the original code’s encode. clean_cohort() applies it to race, sex and age group in both sheets.
  • Race groups from codes, per sheet. group_race_codes() maps race_code to race_group with race_group_codes_study or race_group_codes_control (setup.R); 02 prints the code-to-value table. The stacked data use race_group, sex and age group as text-labelled factors, never codes.
  • Reported quantities. effect_by_level() (Stata’s lincom) and wald_test() (Stata’s testparm) work from model_coefficients(), which handles both clogit() and glmer() models. Interaction coefficient names come from interaction_terms(), built from model$xlevels, so they match exactly.
  • Results in nested named lists. Repeated fits are for-loops over names into lists indexed [[characteristic]][[outcome]], or [[sample]][[outcome]] in 05.
  • Skipped models in one place. skipped_rush_subgroup_models and skipped_era_subgroup_models_all (setup.R) list the models the original code could not fit; 04 and 05 skip them by lookup.
  • Two era samples. era_samples holds all_patients and both_eras (patients with rows_per_patient_both_eras rows); every model in 05 loops over both.
  • One layout for computed and published tables. format_table_1() and format_outcome_table() take rows of text, so R/tables.R (from the data) and the published-results pages (from the article’s printed values in quarto/published/, read by quarto/_published_values.R) produce tables with the same layout.
  • Teaching figures apart from the analysis. R/teaching_figures.R sources setup.R and functions.R itself, as main.R does, and draws the site’s figures with ggplot2 from the published-values CSV and the constants in define-teaching-figure-constants; main.R never sources it, and it reads no study data. It writes SVG files with svglite to quarto/teaching_figures/, which are committed; the site shows them and quarto/teaching_figures.qmd shows its code.
  • Inputs are checked. 01 stops if RUSH_DATA_DIR is unset or a workbook lacks an expected column; the message names columns only. check_unique_patients() stops the import if a patient number repeats in any sheet.

Dependencies outside this repository

  • The study data, in the folder named by RUSH_DATA_DIR: the two de-identified workbooks. Neither is in the repository; their columns have not been checked against the code.
  • Packages attached in setup.R: tidyverse, readxl, survival, lme4 and gtsummary (with gt to save the tables). The synthetic test also needs writexl, and R/teaching_figures.R needs svglite.

Website

Each definitive script has a page in quarto/ that imports its labelled sections with knitr::read_chunk() and shows them without running them. quarto/_stata_sections.R reads stata/RUSH_analysis_2015-01-15.do as text and splits it into 29 parts, each starting at one of the file’s own comment lines (it stops if an anchor is missing); quarto/original_stata.qmd shows every part with a link to its R page, and each script page shows its parts in folded boxes beside the R that replaces them. .github/workflows/publish.yml renders the site and publishes it to gh-pages.

Tests

tests/synthetic/build_synthetic_data.R writes random workbooks with the expected sheets, columns and value formats. tests/synthetic/run_pipeline.R runs R/main.R on them and checks that: the conditional odds ratio for paired data equals the ratio of discordant pairs; effect_by_level() equals a model fitted within each age group; wald_test() equals survival’s Wald test and the squared z statistic; every interaction test found its coefficients; the era subgroup model equals the full-factorial model, with the age main effect estimated; the restricted era sample has four rows per patient; paired_mcnemar() equals mcnemar.test(); the interval for the visit is the Wald interval of the discordant pairs and the Total row of Table 2 shows it; and, on small invented data, that a category in which no patient got worse prints “∞” and “-”, that a category with only uninformative patients is reported as not estimable with the others correctly labelled, that repeated patient numbers stop the import, that McNemar’s test without discordant pairs returns missing values; that the four tables are built and saved; and that R/teaching_figures.R runs and writes its six figures. .github/workflows/test-pipeline.yml runs it on every pull request.

Glossary

Term Definition
post_visit 0 for the window before the visit, 1 for the window after it (Stata’s Intervention)
rush_era 1 for the RUSH-era index visit, 0 for the pre-RUSH visit (Stata’s RUSHEra)
race_code Stata encode number of the recorded race text, within one sheet
race_group Black, Hispanic, White, Asian/Other/Unknown (Stata’s NewRace)
vl_suppressed_missing_fail Viral suppression with a missing result counted as not suppressed; the primary viral load outcome (Stata’s ViralLoadMissEqFail)
vl_suppressed Viral suppression with a missing result missing (Stata’s ViralLoad)
