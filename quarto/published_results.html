ResultsWhere these numbers come from

Every number on this page is quoted from the published article (Flash et al. 2015), with its place there. None was produced by the code in this repository, which has not been run on the study data. The four tables below are rebuilt from the values the article prints, typed in from it, and laid out by the same functions that R/tables.R applies to the data; the article’s own typeset tables and Figure 1 are in the article (author manuscript in PubMed Central).

This page is a map from each reported result to the step of the code that computes it, so that a reader can see what each number is and an authorized analyst can check the R version against the article.

## The published tables

The article's Tables 1 to 4, with the values as printed. Under each table, the code that lays it out (click to show). The same functions build these tables from the data in [`R/tables.R`](tables.qmd), so this is what that script's output looks like, filled with the published values.

```{r}
#| label: read-published-values
#| eval: true
#| include: false
# Reads only the two files of values typed in from the article, and defines
# the table functions; reads no study data and fits nothing.
library(dplyr)
library(tidyr)
library(stringr)
library(readr)
library(gtsummary)
source("../R/functions.R")
read_printed <- function(file) {
  read_csv(file, col_types = cols(.default = col_character()), na = character())
}
published_table_1 <- read_printed("published/table_1.csv")
published_tables_2_to_4 <- read_printed("published/tables_2_to_4.csv")
published_rows <- function(table_name) {
  published_tables_2_to_4 |>
    filter(table == table_name) |>
    select(-table)
}
```
