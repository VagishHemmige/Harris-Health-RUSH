Packages

Five packages besides the tidyverse. readxl reads the two de-identified Excel workbooks, the only data the analysis uses. survival provides clogit(), R’s conditional logistic regression, the model behind almost every result (Therneau, n.d.). lme4 provides glmer(), used only for the random-intercept comparison models that replace Stata’s xtlogit (Bates et al. 2015). gtsummary lays out the article’s four tables (Tables). The original code needed no packages: everything was built into Stata.

Data files

The workbooks are found only through the RUSH_DATA_DIR setting, which an authorized analyst puts in their own .Renviron; the repository holds no path to them. The original code had a global, $DateOfAnalysis, holding the date in the file names, and set Stata’s working directory to a folder on the analyst’s computer. Here the date is a constant and the folder is the setting.

# that date, as in the Stata file's $DateOfAnalysis global.
data_dir <- Sys.getenv("RUSH_DATA_DIR")
analysis_date <- "1-15-2015"
years_since_dx_file <- str_glue("Deidentified Years_After_DX {analysis_date}.xlsx")
rush_data_file <- str_glue("Deidentified RUSH data {analysis_date}.xlsx")
study_cohort_sheet <- "Study Cohort"
control_cohort_sheet <- "Controls"
# read_excel() guesses each column's type from its first 1,000 rows by
# default; a text column that is empty there (a viral load result, say)
# could be read as logical and lose its later values. Guessing from every
# row, as Stata's import excel types the whole column, avoids that.
excel_guess_rows <- 1e6

Expected columns

The columns the original code reads, spelled exactly as it spells them, including its inconsistency: EngageInCare_Before but EngagedInCare_After. 1. Import data stops if any is missing, so a renamed column fails loudly instead of silently producing an empty variable. Their meaning comes from the article’s Methods (analysis plan §7); there is no data dictionary, and a name alone is never taken as a definition.

The original code never reads the year of the visit from the control sheet, so the control sheet is not required to have it. The _Place columns record where each visit or test happened; the original code dropped them unused, and so does this version.

Categories

Years since diagnosis comes as text groups, and the original code turned them into numbered categories in this order, “5 or fewer” first, so that group is the reference. Viral load comes as the text “Suppressed” or “Not Suppressed”; anything else, including an empty cell, is missing.

Race needs the longest comment. The original code turned the recorded race text into numbers with Stata’s encode, which numbers distinct values alphabetically, and then grouped the numbers, not the text: in the study sheet codes 4 and 7 are White, 1, 5 and 6 are Asian, other or unknown. Because each sheet was encoded separately, and the control sheet has fewer distinct values, the same code means different things in the two sheets, so each sheet has its own list. The lists are copied from the original code. What text each number stands for is not documented outside the data, so it is still to be checked; 2. Build long data prints the table needed for the check.

Study design and methods explains why race is used in four groups.

race_group_levels <- c("Black", "Hispanic", "White", "Asian/Other/Unknown")
race_group_codes_study <- list(
  Black = 2,
  Hispanic = 3,
  White = c(4, 7),
  `Asian/Other/Unknown` = c(1, 5, 6)
)
race_group_codes_control <- list(
  Black = 2,
  Hispanic = 3,
  White = 5,
  `Asian/Other/Unknown` = c(1, 4)
)
# The original code's AfricanAmerican indicator is race code 2 in both sheets
african_american_code <- 2

Models the original code could not fit

Three models are commented out in the original code, each with a note that the fit failed: race as recorded with viral suppression (missing excluded), and, in the era comparison with every patient, the race groups with viral suppression (missing as failure) and with retention. A conditional logistic regression fails like this when some combination of categories has no patients whose outcome changed, so a coefficient has no finite estimate. The R version skips the same three, so it fits the same set of models; the lists are tables so a reader can see them at a glance.

Click to show/hide R Code 
# Models the original code did not run, each commented out there because the
# fit failed ("regression fails"; "data sparseness"). They are skipped here
# too, so the R port fits the same set of models (quarto/differences.qmd).
skipped_rush_subgroup_models <- tribble(
  ~outcome,        ~subgroup,
  "vl_suppressed", "race"
)
skipped_era_subgroup_models_all <- tribble(
  ~outcome,                     ~subgroup,
  "vl_suppressed_missing_fail", "race_group",
  "retained_in_care",           "race_group"
)

Estimation constants

95% confidence intervals; 12 quadrature points for the random-intercept models, Stata’s default for xtlogit; and four, the number of rows a patient with a visit in both eras has once the data are long (before and after each visit), which defines the restricted era sample.

Click to show/hide R Code 
confidence_level <- 0.95
# Random-effects models: adaptive Gauss-Hermite quadrature with 12 points,
# Stata's default for xtlogit
quadrature_points <- 12
# Patients with both a RUSH-era and a pre-RUSH visit have four rows in the
# long data: before and after each visit
rows_per_patient_both_eras <- 4
