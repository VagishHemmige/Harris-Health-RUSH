Read years since diagnosis

The second workbook has one row per patient in the RUSH-era cohort: the number of years from HIV diagnosis to the index visit, and the same in five groups. factor() with the levels from Setup puts the groups in order and turns any text not among them into a missing value, which is what the original code’s five replace … if Category == … lines did.

Click to show/hide R Code 
# One row per patient in the RUSH-era cohort: years from HIV diagnosis to
# the index visit, as a number and in five groups. A group text other than
# the five listed in setup.R becomes missing, as in the original code.
years_since_dx <- read_excel(
  file.path(data_dir, years_since_dx_file),
  sheet = study_cohort_sheet,
  guess_max = excel_guess_rows
) |>
  check_columns(years_since_dx_columns, years_since_dx_file) |>
  check_unique_patients("PatientNumber", years_since_dx_file) |>
  transmute(
    PatientNumber,
    years_since_dx = Years_between_DX_and_Index_Visit,
    years_since_dx_group = factor(Category, levels = years_since_dx_levels)
  )

Merge years since diagnosis

Join the two by patient number. The original code used merge 1:1, which keeps every row of both files, matched or not, and then tabulated how many matched (tab _merge). full_join() keeps every row the same way. Before the join, check_unique_patients() stops if a patient number appears twice in either file, as Stata’s 1:1 does; relationship = "one-to-one" alone would check only the matched rows, so a repeated patient missing from the other file would get through. The control sheet gets the same check, standing in for the check Stata’s reshape …, i(PatientNumber) made: a repeated row would add rows to the patient’s stratum and break the four-row rule for the era comparison. The two marker columns exist only to count matched and unmatched patients, which is printed for the analyst and not saved.

Keeping unmatched patients is the original code’s choice; a patient with no years-since-diagnosis value simply drops out of the models that use it.

Click to show/hide R Code 
# The original code merged one to one on PatientNumber and kept every row,
# matched or not ("merge 1:1", then "tab _merge"). full_join() keeps every
# row in the same way. Each file was checked above for repeated patient
# numbers, as Stata's 1:1 requires; relationship = "one-to-one" repeats the
# check for matched rows. The count of matched and unmatched patients
# is printed for the authorized analyst, as "tab _merge" showed it.
study_merged <- study_raw |>
  mutate(in_cohort_sheet = TRUE) |>
  full_join(
    years_since_dx |> mutate(in_years_sheet = TRUE),
    by = "PatientNumber",
    relationship = "one-to-one"
  )
study_merged |>
  count(
    in_cohort_sheet = coalesce(in_cohort_sheet, FALSE),
    in_years_sheet = coalesce(in_years_sheet, FALSE)
  ) |>
  print()

Describe the study cohort

The original code tabulated race, sex, age group, year and years since diagnosis, and summarized years since diagnosis in detail, with the comment that this was to confirm the results matched the manuscript. The same counts and the same percentiles that Stata’s summarize, detail shows are printed here for the analyst. They are the numbers behind the cohort description on Published results.

Click to show/hide R Code 
# The tabulations the original code ran "to confirm that the results are
# the same as in the manuscript". They print counts for the authorized
# analyst; nothing is saved.
for (variable in c("race", "gender", "age_group", "index_test_year",
                   "years_since_dx_group")) {
  print(count(study_wide, .data[[variable]]))
}
print(summary(study_wide$years_since_dx))
print(quantile(
  study_wide$years_since_dx,
  probs = c(0.01, 0.05, 0.10, 0.25, 0.50, 0.75, 0.90, 0.95, 0.99),
  na.rm = TRUE
))

Read the control cohort

The “Controls” sheet: one row per patient with a qualifying pre-RUSH visit (analysis plan §6), the same patients and patient numbers as in the study cohort, with the same columns except that the visit year is not needed. It gets the same cleaning, so its sex and age group are factors too. Its race codes are numbered from its own values, which is why the race groups in the next script use a separate list for this sheet.

Click to show/hide R Code 
# One row per patient with a qualifying pre-RUSH visit (analysis-plan.md
# section 6). These patients are a subset of the RUSH-era cohort, with the
# same PatientNumber.
control_wide <- read_excel(
  file.path(data_dir, rush_data_file),
  sheet = control_cohort_sheet,
  guess_max = excel_guess_rows
) |>
  check_columns(control_columns, str_glue("{rush_data_file}, {control_cohort_sheet}")) |>
  check_unique_patients("PatientNumber", str_glue("{rush_data_file}, {control_cohort_sheet}")) |>
  clean_cohort(place_columns)

for (variable in c("race", "gender", "age_group")) {
  print(count(control_wide, .data[[variable]]))
}
