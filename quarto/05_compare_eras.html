Two samples

The original code first fitted the era models with every patient, with a comment that this was done by request, and then kept only patients with four rows and fitted them again. Both are kept here, as a named list of two data frames, so every later step runs on each in a loop. The printed table counts patients by number of rows: two (a RUSH-era visit only) or four (both eras).

Decision pending: which of the two samples produced the P values the article reports for the era comparison is decision issue #2.

# first "by request" with every patient, including those with a RUSH-era

    add_count(patient_number, name = "rows_per_patient") |>

    select(-rows_per_patient)

The era model

post_visit * rush_era, which R expands to post_visit + rush_era + post_visit:rush_era, within patient strata (Methodological background):

  • post_visit: the change around a pre-RUSH visit (the article’s P = 0.017 for engagement);
  • rush_era: the difference between the periods before each era’s visit;
  • post_visit:rush_era: how many times larger the odds ratio for the RUSH-era visit was. This is the P value the article reports for each outcome’s era comparison.

A patient with a RUSH-era visit only has a constant rush_era, so the era main effect cancels from their stratum. Their two rows inform the change around the RUSH-era visit, which in this model is the sum post_visit + post_visit:rush_era. On their own they cannot separate the two coefficients, but pooled with the both-era patients they pull that sum toward their own change, and so move the estimated interaction and its standard error. That is why the two samples can give different era P values, the question decision issue #2 asks which the article used.

Click to show/hide R Code 
# Within each patient: post_visit is the change around a pre-RUSH visit,
# rush_era the difference between the periods before each era's visit,
# and post_visit:rush_era how much larger (as a ratio of odds ratios) the
# change around the RUSH-era visit was. The interaction is the test the
# article reports for each outcome.
era_models <- list()
era_effects <- list()
for (sample in names(era_samples)) {
  for (outcome in names(outcomes)) {
    model <- fit_conditional_logit(
      era_samples[[sample]], outcome, "post_visit * rush_era"
    )
    era_models[[sample]][[outcome]] <- model
    era_effects[[sample]][[outcome]] <- tidy_odds_ratios(model, confidence_level)
  }
}

Does the pattern differ by characteristic?

Every term of the era model interacted with the characteristic: post_visit * rush_era * gender adds post_visit:genderMale, rush_era:genderMale and post_visit:rush_era:genderMale to the era model, as Stata’s i.Intervention##i.RUSHEra##i.Gender does. Unlike the RUSH-era models, the characteristic’s own main effect is kept. Each era’s rows take sex, age group and race from that era’s sheet, and age group in particular is the age at that era’s visit, years apart, so it can change within a patient; then its main effect is estimable, and leaving it out would fit a different model. Where a characteristic is the same in all of every patient’s rows, clogit() returns its main effect as NA and Stata omits it, with the same result. The joint Wald test of all these interaction terms asks whether any part of the pattern differs by the characteristic, which is what the original code’s testparm lists tested. The original code itself called these models complicated and included them for completeness.

Two models could not be fitted with every patient and are skipped there; with patients from both eras the original code fitted all of them, and so does this version.

Click to show/hide R Code 
# Whether any of the era terms differ by a characteristic: every term of
# the era model interacted with it, Stata's
# "i.Intervention##i.RUSHEra##i.<characteristic>", and one joint Wald test
# of all the interaction terms, as the original code's testparm. The
# characteristic's own main effect is kept: each era's rows take the
# characteristic from that era's sheet, so age group, for example, can
# differ between a patient's pre-RUSH and RUSH-era rows, and then the main
# effect is estimable. Where it is constant within every patient, clogit()
# returns it as NA, as Stata omits it. Models the original code could not
# fit with every patient are skipped there (R/setup.R).
era_subgroup_models <- list()
era_subgroup_tests <- list()
for (sample in names(era_samples)) {
  for (subgroup in names(subgroups_era)) {
    for (outcome in names(outcomes)) {
      skipped <- skipped_era_subgroup_models_all |>
        filter(.data$outcome == .env$outcome, .data$subgroup == .env$subgroup)
      if (sample == "all_patients" && nrow(skipped) > 0) {
        next
      }
      model <- fit_conditional_logit(
        era_samples[[sample]],
        outcome,
        str_glue("post_visit * rush_era * {subgroup}")
      )
      era_subgroup_models[[sample]][[subgroup]][[outcome]] <- model
      subgroup_levels <- model$xlevels[[subgroup]]
      era_subgroup_tests[[sample]][[subgroup]][[outcome]] <- wald_test(
        model,
        c(
          interaction_terms("post_visit", subgroup, subgroup_levels),
          interaction_terms("rush_era", subgroup, subgroup_levels),
          interaction_terms("post_visit:rush_era", subgroup, subgroup_levels)
        )
      )
    }
  }
}

Random-intercept models

For comparison, the era model with a random intercept per patient, (1 | patient_number), in place of the strata: R’s version of Stata’s xtset PatientNumber and xtlogit. nAGQ = 12 asks for adaptive Gauss–Hermite quadrature with 12 points, Stata’s default. Unlike the conditional model it also uses differences between patients, and assumes the patient effect is unrelated to the visit and the era (Methodological background). Similar answers from the two kinds of model are reassuring; the article reports the conditional one.

Click to show/hide R Code 
# For comparison, the same era model with a random intercept for each
# patient instead of a stratum, the R equivalent of Stata's xtlogit. Unlike
# the conditional model, it also uses the differences between patients, so
# it assumes the random intercept is unrelated to the visit and era.
random_effects_models <- list()
random_effects_effects <- list()
for (sample in names(era_samples)) {
  for (outcome in names(outcomes)) {
    model <- glmer(
      as.formula(str_glue("{outcome} ~ post_visit * rush_era + (1 | patient_number)")),
      data = era_samples[[sample]],
      family = binomial,
      nAGQ = quadrature_points
    )
    random_effects_models[[sample]][[outcome]] <- model
    random_effects_effects[[sample]][[outcome]] <- tidy_odds_ratios(
      model, confidence_level
    )
  }
}
